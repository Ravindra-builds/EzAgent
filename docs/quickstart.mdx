# 30-Second Quickstart

Get up and running with a functional AI agent in 30 seconds.

---

## 1. Minimal Working Example

Create a file named `quickstart.ts`:

```typescript
import { Agent, OpenAIProvider, Runner } from "ezagent";

// 1. Initialize the Provider
const provider = new OpenAIProvider({
  apiKey: process.env.OPENAI_API_KEY!
});

// 2. Define the Agent configuration
const agent = new Agent({
  name: "Assistant",
  instructions: "You are a helpful, concise assistant. Answer questions in 1-2 sentences.",
  model: "gpt-4.1-mini",
  provider
});

// 3. Create the Runner instance
const runner = new Runner();

// 4. Run the Agent
const result = await runner.run(agent, {
  input: "What is an AI agent SDK?"
});

// 5. Output the result
console.log("Agent Output:", result.output);
console.log("Execution Time:", result.trace.durationMs, "ms");
```

Run the file using `tsx` or `ts-node`:

```bash
npx tsx quickstart.ts
```

## 2. Interactive Playground CLI

EzAgent ships with an interactive local CLI playground for rapid experimentation:

```bash
# 1. Copy the environment template
cp .env.example .env

# 2. Add your API key to .env
# OPENAI_API_KEY=sk-...

# 3. Launch the playground
npm run playground
```

### Interactive Playground Commands

| Command  | Description                                                |
| -------- | ---------------------------------------------------------- |
| `/trace` | Display the complete JSON execution trace of the last run. |
| `/reset` | Clear the active session transcript history.               |
| `/exit`  | Exit the interactive playground.                           |

---

## What Happened Under the Hood?

When you called `runner.run(agent, { input: "..." })`:

1. `Runner` constructed the execution context and initialized a new run state.
2. `Runner` formatted the prompt messages (`system` instructions + `user` input).
3. `Runner` sent the request to `OpenAIProvider.chat()`.
4. `OpenAIProvider` converted vendor response formats into standard EzAgent types.
5. `Runner` stored trace metadata and returned a structured `RunResult`.
