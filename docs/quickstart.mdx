# 30-Second Quickstart

Get up and running with a functional AI agent in 30 seconds.

---

## 1. Quickstart Code Example

Create a file named `quickstart.ts` in your project folder:

```typescript quickstart.ts
import "dotenv/config"; // 1. Load .env variables at the very top
import { Agent, OpenAIProvider, Runner } from "ezagent";

// 2. Initialize the LLM Provider
const provider = new OpenAIProvider({
  apiKey: process.env.OPENAI_API_KEY!
});

// 3. Define the Agent configuration
const agent = new Agent({
  name: "Assistant",
  instructions: "You are a helpful, concise assistant. Answer questions in 1-2 sentences.",
  model: "gpt-4.1-mini",
  provider
});

// 4. Create the Runner instance
const runner = new Runner();

// 5. Run the Agent
const result = await runner.run(agent, {
  input: "What is an AI agent SDK?"
});

// 6. Output the result
console.log("Agent Output:", result.output);
console.log("Execution Time:", result.trace.durationMs, "ms");
```

Run the file directly using `npx tsx`:

```bash
npx tsx quickstart.ts
```

## 2. Setting Up an Interactive Playground (`npm run playground`)

You can create an interactive terminal CLI playground in your own project where you can chat with your agent in real-time.

### Step A: Add `"playground"` script to your `package.json`

Add `"playground": "tsx playground.ts"` to your `package.json` `scripts` section:

```json package.json
{
  "name": "my-ai-agent",
  "version": "1.0.0",
  "type": "module",
  "scripts": {
    "playground": "tsx playground.ts"
  }
}
```

---

### Step B: Create `playground.ts` File

Create a file named `playground.ts` in your project root folder and paste this interactive loop:

```typescript playground.ts
import "dotenv/config"; // 1. Load .env variables
import readline from "node:readline/promises";
import { Agent, OpenAIProvider, Runner } from "ezagent";

// 2. Initialize Provider and Agent
const provider = new OpenAIProvider({
  apiKey: process.env.OPENAI_API_KEY!
});

const agent = new Agent({
  name: "PlaygroundAssistant",
  instructions: "You are a helpful AI assistant. Keep responses clear and concise.",
  model: "gpt-4.1-mini",
  provider
});

const runner = new Runner();
const rl = readline.createInterface({
  input: process.stdin,
  output: process.stdout
});

console.log("🚀 EzAgent Interactive Playground Started!");
console.log("Type your prompt and press Enter (or type '/exit' to quit):\n");

// 3. Interactive CLI loop
while (true) {
  const input = await rl.question("> ");

  if (input.trim() === "/exit") {
    console.log("Exiting playground. Goodbye!");
    break;
  }

  if (!input.trim()) continue;

  const result = await runner.run(agent, { input });
  console.log(`\n🤖 ${result.output}\n`);
}

rl.close();
```

---

### Step C: Run the Playground

Start your interactive playground anytime by running:

```bash
npm run playground
```

Output:

```text
🚀 EzAgent Interactive Playground Started!
Type your prompt and press Enter (or type '/exit' to quit):

> Hello! Who are you?

🤖 I am PlaygroundAssistant, an AI assistant built using EzAgent.
```

---

## What Happened Under the Hood?

When `runner.run(agent, { input: "..." })` executes:

1. `Runner` initializes the execution state and validates prompt input.
2. `Runner` formats system instructions and conversation messages.
3. `Runner` sends the request to the LLM provider (`OpenAIProvider` or `GeminiProvider`).
4. Provider normalizes vendor HTTP responses into standard EzAgent output format.
5. `Runner` records timing, trace telemetry, and returns a structured `RunResult`.
