# API Reference

Complete exported classes, factory functions, types, and error codes in `ezagent`.

---

## Core Exports

### `Agent`

```typescript
class Agent<TOutput = string> {
  constructor(config: AgentConfig<TOutput>);
  readonly name: string;
  readonly instructions: string;
  readonly model: string;
  readonly provider: Provider;
  readonly tools: readonly Tool[];
  readonly guardrails: AgentGuardrails;
  readonly handoffs: readonly Handoff[];
  readonly plugins: readonly AgentPlugin[];
  readonly middleware: readonly RunnerMiddleware[];
  readonly memory?: Readonly<AgentMemoryConfig>;
  readonly output?: StructuredOutputDefinition<TOutput>;

  /** Finds a configured tool by its name. */
  getTool(name: string): Tool | undefined;

  /** Finds a configured handoff by its tool name. */
  getHandoff(toolName: string): Handoff | undefined;

  /** Returns a new Agent with the given handoffs. Original is unchanged. */
  withHandoffs(handoffs: readonly Handoff[]): Agent<TOutput>;

  /** Returns a new Agent with an additional plugin. Original is unchanged. */
  use(plugin: AgentPlugin): Agent<TOutput>;

  // Note: There is NO .withTools() method.
  // To change tools, create a new Agent with new Agent({ ...existingConfig, tools: [...] })
}
```

### `Runner`

```typescript
class Runner {
  constructor(config?: RunnerConfig);
  run<TContext, TOutput>(
    agent: Agent<TOutput>,
    options: RunOptions<TContext>
  ): Promise<RunResult<TOutput>>;

  stream<TContext, TOutput>(
    agent: Agent<TOutput>,
    options: RunOptions<TContext>
  ): AsyncIterable<RunStreamEvent<TOutput>>;

  on<K extends keyof RunnerEventMap>(
    event: K,
    listener: (event: RunnerEventMap[K]) => void
  ): () => void;
}
```

## Factory Functions

- `tool(config)`: Constructs a Zod-validated `Tool`.
- `handoff(targetAgent, config?)`: Constructs a model-visible `Handoff` delegation tool.
- `guardrail(config)`: Constructs a named `Guardrail`.
- `middleware(config)`: Constructs a `RunnerMiddleware` hook object.
- `plugin(config)`: Constructs an `AgentPlugin`.
- `allow`: Pre-built `GuardrailDecision` allowing execution.
- `block(reason, metadata?)`: Constructs a blocking `GuardrailDecision`.

## Error Classes Hierarchy

All SDK exceptions inherit from `EzAgentError`:

| Error Class                  | Code                           | Description                                         |
| ---------------------------- | ------------------------------ | --------------------------------------------------- |
| `AgentError`                 | `AGENT_ERROR`                  | Bounded limit exceeded or invalid configuration.    |
| `ProviderError`              | `PROVIDER_ERROR`               | LLM HTTP network or response decoding failure.      |
| `ProviderConfigurationError` | `PROVIDER_CONFIGURATION_ERROR` | Missing or invalid API key / base URL credentials.  |
| `ToolError`                  | `TOOL_ERROR`                   | Tool execution exception or schema violation.       |
| `GuardrailError`             | `GUARDRAIL_ERROR`              | Guardrail blocked operation.                        |
| `HandoffError`               | `HANDOFF_ERROR`                | Circular or exhausted multi-agent handoff.          |
| `TimeoutError`               | `TIMEOUT_ERROR`                | Run deadline exceeded.                              |
| `ValidationError`            | `VALIDATION_ERROR`             | Input, output, or metadata schema validation error. |
| `StorageError`               | `STORAGE_ERROR`                | Session storage persistence failure.                |
| `MemoryError`                | `MEMORY_ERROR`                 | Factual memory adapter retrieval failure.           |
