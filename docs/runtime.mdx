# Runtime Engine (`Runner`)

The `Runner` class is the core execution engine of EzAgent. It owns state management, session loading/saving, tool execution, safety evaluation, retry loops, and telemetry tracing.

---

## Runner Execution Lifecycle

Each call to `runner.run(agent, options)` runs through a bounded execution loop:

```text
1. Initialize Run Context & Trace Collector
   │
2. Execute Middleware 'before' Hooks
   │
3. Evaluate Input Guardrails (reject if blocked)
   │
4. Load Session Transcript (if sessionId provided)
   │
5. Retrieve Long-Term Memory (if memory query configured)
   │
6. Execute LLM Provider Chat/Stream Turn
   ├── If Model requests Tool Call → Run Tool & loop back to Step 6
   ├── If Model requests Handoff → Switch Agent & loop back to Step 6
   └── If Model returns Response → Proceed to Step 7
   │
7. Validate Structured Output (repair & retry if schema validation fails)
   │
8. Evaluate Output Guardrails
   │
9. Save Session Transcript & Execute Middleware 'after' Hooks
   │
10. Return RunResult
```

## Bounded Execution Limits

To prevent runaway infinite loops, unconstrained tool executions, or unexpected API costs, `Runner` enforces configurable execution boundaries:

```typescript
import { Runner } from "ezagent";

const runner = new Runner({
  maxIterations: 10, // Max LLM turn iterations per run (default: 10)
  maxToolCalls: 25, // Max total tool calls per run (default: 25)
  maxHandoffs: 5, // Max agent delegations (default: 5)
  maxOutputRetries: 3, // Max structured output repair retries (default: 3)
  timeoutMs: 120_000, // Total run deadline in milliseconds (default: 120,000)
  retry: {
    maxAttempts: 3, // Max attempts for retryable provider errors (default: 3)
    initialDelayMs: 500, // Exponential backoff initial delay (default: 500ms)
    maxDelayMs: 10_000 // Backoff max delay cap (default: 10,000ms)
  }
});
```

## Cancellation & Deadlines

Pass an `AbortSignal` to cancel a running execution gracefully:

```typescript
const controller = new AbortController();

// Cancel run after 5 seconds if not completed
setTimeout(() => controller.abort(new Error("Operation cancelled by user")), 5000);

try {
  const result = await runner.run(agent, {
    input: "Analyze this large dataset...",
    signal: controller.signal
  });
} catch (error) {
  if (error instanceof Error && error.message.includes("cancelled")) {
    console.log("Run was safely aborted.");
  }
}
```

## Event Bus Subscriptions

`Runner` emits typed runtime events that allow you to monitor progress in real time:

```typescript
runner.on("run:start", ({ runId, agentName }) => {
  console.log(`[${runId}] Started run for ${agentName}`);
});

runner.on("model:start", ({ model, iteration }) => {
  console.log(`[Turn ${iteration}] Calling model ${model}`);
});

runner.on("tool:start", ({ toolName, toolCallId }) => {
  console.log(`Executing tool: ${toolName} (${toolCallId})`);
});

runner.on("completed", ({ runId, durationMs }) => {
  console.log(`[${runId}] Completed in ${durationMs}ms`);
});

runner.on("failed", ({ runId, error }) => {
  console.error(`[${runId}] Failed: ${error.message}`);
});
```
