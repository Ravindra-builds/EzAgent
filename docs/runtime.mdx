# Runtime Engine

The `Runner` is the execution engine of EzAgent. It runs a bounded loop that connects the Agent, Provider, Tools, and Storage.

## How the Loop Works

1. **Input Guardrails**: Evaluates safety rules on the user input.
2. **Provider Request**: Sends messages to the model via the configured provider adapter.
3. **Tool Calls / Handoffs**: If the model requests a tool call or handoff, `Runner` executes it safely.
4. **Output Guardrails**: Verifies model response before returning it.
5. **Return Result**: Returns a `RunResult` containing the final output, full transcript, trace log, and usage stats.

## Configuring Runner Limits

Prevent runaway loops or unexpected API bills by setting explicit limits:

```typescript
import { Runner } from "ezagent";

const runner = new Runner({
  maxIterations: 10, // Max LLM turn loops (default: 10)
  maxToolCalls: 25, // Max total tool calls per run (default: 25)
  maxHandoffs: 5, // Max agent delegations (default: 5)
  timeoutMs: 60_000 // Overall deadline in milliseconds (default: 120,000)
});
```

## Run Result Structure

When you call `runner.run()`, it returns a `RunResult`:

```typescript
const result = await runner.run(agent, { input: "Hello" });

console.log(result.output); // Final model response text or object
console.log(result.agentName); // Starting agent name
console.log(result.finalAgentName); // Agent active when run completed
console.log(result.messages); // Immutable transcript history
console.log(result.iterations); // Number of LLM iterations taken
console.log(result.toolCalls); // Total tool executions
console.log(result.trace); // Complete execution trace
```
