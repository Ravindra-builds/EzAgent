# Introduction to EzAgent

**EzAgent** is a lightweight, provider-agnostic TypeScript SDK designed for building production-grade AI agents with **complete runtime transparency**.

Unlike heavy agent frameworks that obscure model calls, tool execution, and state management behind complex abstractions, EzAgent gives developers direct visibility and control over every step of the agent execution lifecycle.

---

## Key Highlights

- 🪶 **Lightweight & Modular**: Small dependency footprint (only peer-depends on Zod). No forced platform or cloud lock-in.
- 🔌 **Provider Agnostic**: Run the exact same Agent using OpenAI, Google Gemini, or your own custom LLM provider interface.
- 🔍 **Transparent Runtime**: Complete inspection of transcripts, tool executions, retries, multi-agent handoffs, and step-by-step traces.
- 🛡️ **Built-in Guardrails & Safety**: Inspect and approve or block user inputs, model outputs, tool calls, and human approvals.
- 🔄 **Structured Output & Auto-Repair**: Define typed output schemas with Zod. EzAgent automatically repairs invalid JSON responses.
- 📡 **Real-Time Streaming**: Stream text tokens, tool execution events, and results using standard `for await...of` async iterators.
- 🤖 **Multi-Agent Handoffs**: Transfer execution between specialized agents with built-in loop detection and delegation limits.

---

## Architectural Invariants

EzAgent is built on strict design invariants to guarantee predictability in production:

1. **Agent is Immutable Configuration**: An `Agent` holds static metadata (name, instructions, provider, tools, guardrails). It contains zero execution state.
2. **Runner Owns Execution**: The `Runner` class controls the execution loop, limits, session persistence, memory retrieval, retry policies, and tracing.
3. **Bounded Execution**: Every run is strictly bounded by maximum iterations, tool calls, handoffs, output repair attempts, and total execution timeout.
4. **Type-Safe Validation**: Tools and structured outputs rely on Zod for runtime schema validation.
