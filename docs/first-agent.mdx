# Creating Your First Agent

In EzAgent, an `Agent` is an **immutable configuration container**. It defines _who_ the agent is, _what instructions_ it follows, _which provider and model_ it uses, and _what tools or safety rules_ it possesses.

---

## Defining an Agent

Use the `Agent` class constructor to build your configuration:

```typescript
import { Agent, OpenAIProvider } from "ezagent";

const supportAgent = new Agent({
  name: "CustomerSupportAgent",
  instructions: `
    You are a customer support agent for TechCorp.
    Always be polite, helpful, and concise.
    If you do not know the answer, state that clearly instead of guessing.
  `,
  model: "gpt-4.1-mini",
  provider: new OpenAIProvider({ apiKey: process.env.OPENAI_API_KEY! })
});
```

---

## Agent Configuration Options

| Option         | Type                 | Required | Description                                                               |
| -------------- | -------------------- | -------- | ------------------------------------------------------------------------- |
| `name`         | `string`             | **Yes**  | Identifier for the agent used in traces, logs, and multi-agent handoffs.  |
| `instructions` | `string`             | **Yes**  | The system prompt that guides model behavior.                             |
| `provider`     | `Provider`           | **Yes**  | The LLM adapter instance (`OpenAIProvider`, `GeminiProvider`, or custom). |
| `model`        | `string`             | **Yes**  | The target model identifier (e.g. `gpt-4.1-mini`, `gemini-2.0-flash`).    |
| `tools`        | `readonly Tool[]`    | No       | Zod-validated tools the model is allowed to invoke.                       |
| `guardrails`   | `AgentGuardrails`    | No       | Input, output, tool, and approval safety checks.                          |
| `handoffs`     | `readonly Handoff[]` | No       | Target agents this agent can delegate requests to.                        |
| `output`       | `ZodSchema`          | No       | Zod schema for enforcing structured JSON responses.                       |

---

## Agent Immutability & Immutability Helpers

Because `Agent` instances are deeply frozen, modifying an agent creates a new immutable instance without mutating the original:

```typescript
// 1. Extend an agent with new tools
const agentWithTools = supportAgent.withTools([searchTool]);

// 2. Extend an agent with multi-agent handoffs
const agentWithHandoffs = supportAgent.withHandoffs([handoff(billingAgent)]);

// 3. Attach plugins to an agent
const agentWithPlugins = supportAgent.use(loggingPlugin);

// The original supportAgent remains untouched!
```

---

## Running the Agent

To execute an agent, pass it to `Runner.run()`:

```typescript
import { Runner } from "ezagent";

const runner = new Runner();
const result = await runner.run(supportAgent, {
  input: "What are your business hours?"
});

console.log(result.output);
```
