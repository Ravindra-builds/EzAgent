# Agent Plugins

Plugins provide a clean way to package reusable middleware hooks and attach them directly to an `Agent`.

---

## Defining a Plugin

Use the `plugin()` factory function:

```typescript
import { middleware, plugin } from "ezagent";

// Create an audit logging plugin
export const auditLoggingPlugin = plugin({
  name: "audit_logger",
  middleware: [
    middleware({
      name: "run_audit",
      before: ({ runId, agent }) => {
        console.log(`[AUDIT] Starting run ${runId} for agent ${agent.name}`);
      },
      after: ({ runId, durationMs }) => {
        console.log(`[AUDIT] Completed run ${runId} in ${durationMs}ms`);
      },
      onError: ({ runId, error }) => {
        console.error(`[AUDIT] Failed run ${runId}: ${error.message}`);
      }
    })
  ]
});
```

---

## Attaching Plugins to an Agent (`.use()`)

Attach plugins using the immutable `.use()` method on `Agent`:

```typescript
import { Agent, OpenAIProvider } from "ezagent";

const agent = new Agent({
  name: "PluginAgent",
  instructions: "Process incoming requests.",
  model: "gpt-4.1-mini",
  provider: new OpenAIProvider({ apiKey: process.env.OPENAI_API_KEY! })
}).use(auditLoggingPlugin);

// agent now carries auditLoggingPlugin's middleware automatically!
```
