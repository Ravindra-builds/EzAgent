# Installation & Setup

EzAgent is published on npm as `ezagent`. It includes ESM, CommonJS, and TypeScript declaration bundles out of the box.

---

## Prerequisites

- **Node.js**: Version 18.0.0 or higher.
- **TypeScript**: Version 5.0 or higher (recommended).
- **Zod**: Version 3.x or 4.x (required peer dependency for tool schemas and structured outputs).

---

## Installing the SDK

Install `ezagent` along with `zod` using your preferred package manager:

<CodeGroup>
```bash npm
npm install ezagent zod
```

```bash pnpm
pnpm add ezagent zod
```

```bash bun
bun add ezagent zod
```

```bash yarn
yarn add ezagent zod
```

</CodeGroup>

---

## Environment Variables

For local development or testing with real LLM providers, create a `.env` file at the root of your project:

```dotenv
# Select provider for the playground CLI (openai | gemini)
EZAGENT_PROVIDER=openai

# OpenAI Credentials
OPENAI_API_KEY=sk-proj-...

# Google Gemini Credentials
GEMINI_API_KEY=AIzaSy...
```

Make sure to install `dotenv` if your project loads environment variables via `import "dotenv/config"`:

```bash
npm install -D dotenv
```

---

## Recommended `tsconfig.json`

For optimal TypeScript performance and autocompletion, configure your `tsconfig.json` with modern Node module resolution:

```json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true
  }
}
```
