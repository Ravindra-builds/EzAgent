# Installation

Installing EzAgent in your TypeScript project takes only a few seconds.

## Requirements

- **Node.js**: Version 18 or newer
- **TypeScript**: Version 5 or newer (recommended)
- **Zod**: Version 3 or 4 (used for defining tools and structured outputs)

## Install via Package Manager

Choose your favorite package manager:

```bash
# npm
npm install ezagent zod

# pnpm
pnpm add ezagent zod

# bun
bun add ezagent zod

# yarn
yarn add ezagent zod
```

## Environment Setup

Create a `.env` file in the root of your project to store your API keys:

```env
OPENAI_API_KEY=your_openai_api_key_here
GEMINI_API_KEY=your_gemini_api_key_here
```

Next, check out the [Quickstart](./quickstart.mdx) to build your first agent!
