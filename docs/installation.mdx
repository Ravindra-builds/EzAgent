# Complete Installation & Project Setup

This guide will take you step-by-step from an empty directory to a fully working EzAgent project. Even if you are brand new to TypeScript and Node.js, you can follow these exact steps to build your first AI agent without any external help.

---

## Step 1: System Requirements

Make sure you have Node.js installed on your computer.

Open your terminal (Command Prompt or PowerShell on Windows, Terminal on macOS/Linux) and run:

```bash
node -v
```

> **Requirement**: Node.js **18.0.0 or higher**. If you need to install or update Node.js, download it from [nodejs.org](https://nodejs.org/).

---

## Step 2: Create a New Project Directory

Create a fresh folder for your project and navigate inside:

```bash
mkdir my-ai-agent
cd my-ai-agent
```

---

## Step 3: Initialize `package.json`

Initialize a new Node.js project to manage dependencies:

```bash
npm init -y
```

This creates a `package.json` file in your directory. Now, enable modern ES Modules support by adding `"type": "module"` to your `package.json`:

```json package.json
{
  "name": "my-ai-agent",
  "version": "1.0.0",
  "type": "module"
}
```

---

## Step 4: Install EzAgent & Dependencies

Install the EzAgent SDK along with its required dependencies and developer tools:

<CodeGroup>
```bash npm
# 1. Primary SDK and Zod Schema Validator
npm install ezagent zod

# 2. Developer Tooling (TypeScript compiler, runner, dotenv)

npm install -D typescript tsx dotenv @types/node

````

```bash pnpm
pnpm add ezagent zod
pnpm add -D typescript tsx dotenv @types/node
````

```bash bun
bun add ezagent zod
bun add -D typescript tsx dotenv @types/node
```

```bash yarn
yarn add ezagent zod
yarn add -D typescript tsx dotenv @types/node
```

</CodeGroup>

### What does each package do?

| Package           | Type                | Why is it needed?                                                                                                  |
| ----------------- | ------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **`ezagent`**     | Primary SDK         | The core EzAgent package containing `Agent`, `Runner`, and Provider adapters (`OpenAIProvider`, `GeminiProvider`). |
| **`zod`**         | Required Dependency | Schema validation library used to define tool parameters and enforce typed JSON outputs.                           |
| **`dotenv`**      | Helper              | Loads your secret API keys from a local `.env` file into Node's `process.env`.                                     |
| **`tsx`**         | Dev Tool            | Fast TypeScript runner that executes `.ts` files directly (`npx tsx index.ts`) without manually compiling first.   |
| **`typescript`**  | Dev Tool            | TypeScript language compiler for autocompletion and type-checking in VS Code or your IDE.                          |
| **`@types/node`** | Dev Tool            | Type definitions for Node.js built-ins (`process.env`, `fetch`, `AbortController`).                                |

## Step 5: Initialize & Configure TypeScript (`tsconfig.json`)

Generate a default TypeScript configuration file by running:

```bash
npx tsc --init
```

Now open the newly created `tsconfig.json` file in your editor. Replace its contents with this recommended, production-ready configuration:

```json tsconfig.json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "types": ["node"],
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true
  }
}
```

### Key `tsconfig.json` Options Explained

- **`"target": "ES2022"`**: Enables modern JavaScript syntax features like top-level `await` and `async/await`.
- **`"module": "NodeNext"` & `"moduleResolution": "NodeNext"`**: Enables native Node.js ES Module (`import/export`) resolution for TypeScript.
- **`"types": ["node"]`**: Tells TypeScript to load Node.js global types automatically (so `process.env` and `fetch` work without errors).
- **`"strict": true`**: Enables strict type checking to catch `null` or `undefined` bugs before your code runs.

## Step 6: Create Your Secret `.env` File

Create a file named `.env` in the root folder of your project and fill the details:

```env .env
# OpenAI API Key
OPENAI_API_KEY=sk-proj-your_actual_openai_key_here

# Or Google Gemini API Key
GEMINI_API_KEY=AIzaSy_your_actual_gemini_key_here
```

> ⚠️ **Security Reminder**: Create a `.gitignore` file in your project root and add `.env` inside it so your secret keys are never committed to GitHub!

---

## Step 7: Complete File & Project Structure

Before running your code, your project directory should look like this:

```text
my-ai-agent/
├── node_modules/       <-- Installed npm dependencies (auto-generated)
├── .env                <-- Your secret API keys
├── .gitignore          <-- Ignores node_modules and .env from Git
├── package.json        <-- Project dependencies & config
├── tsconfig.json       <-- TypeScript configuration
└── index.ts            <-- Your primary AI Agent code (created in Step 8)
```

---

## Step 8: Create & Run Your First Agent (`index.ts`)

Create a file named `index.ts` in your root folder and paste the following code:

```typescript index.ts
import "dotenv/config"; // 1. Load .env variables at the very top
import { Agent, OpenAIProvider, Runner } from "ezagent";

// 2. Create the LLM Provider instance
const provider = new OpenAIProvider({
  apiKey: process.env.OPENAI_API_KEY!
});

// 3. Define the Agent configuration
const agent = new Agent({
  name: "Assistant",
  instructions: "You are a helpful AI assistant. Keep your responses brief and friendly.",
  model: "gpt-4.1-mini",
  provider
});

// 4. Create the Runner and Execute
const runner = new Runner();

console.log("Running Agent...");
const result = await runner.run(agent, {
  input: "Tell me what EzAgent is in one sentence."
});

// 5. Output the result
console.log("\nAgent Output:");
console.log(result.output);
```

### Run Command

Execute your agent directly in your terminal using `tsx`:

```bash
npx tsx index.ts
```

Expected Output:

```text
Running Agent...

Agent Output:
EzAgent is a lightweight, provider-agnostic TypeScript SDK for building and running transparent AI agents.
```
