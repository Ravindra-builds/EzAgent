# Sessions & Conversation History

Sessions manage multi-turn conversation transcripts across multiple runner invocations.

---

## How Sessions Work

1. When you pass `sessionId: "session-123"` to `runner.run()`, `Runner` loads the existing transcript from the configured `storage` adapter.
2. `Runner` appends the new user input message to the loaded transcript.
3. `Runner` executes the agent using the full transcript history.
4. `Runner` appends model responses and tool results to the transcript.
5. `Runner` saves the updated transcript back to `storage`.

---

## Session Usage Example

```typescript
import { Agent, InMemoryStorage, OpenAIProvider, Runner } from "ezagent";

// 1. Create a storage adapter
const storage = new InMemoryStorage();

// 2. Initialize Runner with storage
const runner = new Runner({ storage });

const agent = new Agent({
  name: "SupportAgent",
  instructions: "You are a customer support agent. Help the user step by step.",
  model: "gpt-4.1-mini",
  provider: new OpenAIProvider({ apiKey: process.env.OPENAI_API_KEY! })
});

// Turn 1: User introduces themselves
await runner.run(agent, {
  input: "Hi! My order ID is #98765.",
  sessionId: "customer-session-1"
});

// Turn 2: User asks a follow-up question
const reply = await runner.run(agent, {
  input: "Can you check the status of my order?",
  sessionId: "customer-session-1"
});

console.log(reply.output); // Model references order ID #98765 from Turn 1!
```

## Storing Metadata with Sessions

Attach custom key-value metadata (e.g. `userId`, `tenantId`) when creating a session:

```typescript
await runner.run(agent, {
  input: "Hello",
  sessionId: "session-abc",
  sessionMetadata: {
    userId: "usr_1001",
    channel: "web-chat"
  }
});
```

---

## Managing Session History

Inspect or delete sessions directly using your storage adapter instance:

```typescript
// Load a session manually
const session = await storage.loadSession("customer-session-1");
console.log("Message count:", session?.messages.length);
console.log("Session Metadata:", session?.metadata);

// Delete a session when user logs out
await storage.deleteSession("customer-session-1");
```
