# Tracing & Telemetry

EzAgent tracks detailed execution telemetry for every run via `RunTrace`. Traces record timing, tokens, provider HTTP calls, tool arguments, output repair attempts, guardrail checks, and middleware execution.

---

## Accessing `RunTrace` on Results

Every completed `RunResult` includes a full, immutable `trace` object:

```typescript
const result = await runner.run(agent, { input: "Summarize this document" });

console.log("Run ID:", result.trace.runId);
console.log("Total Duration:", result.trace.durationMs, "ms");
console.log("Status:", result.trace.status); // "completed" | "failed"
console.log("Provider Calls:", result.trace.providerCalls.length);
console.log("Tool Calls:", result.trace.tools.length);
console.log("Retries:", result.trace.retries.length);
```

## `RunTrace` Schema Structure

```typescript
export interface RunTrace {
  readonly runId: string;
  readonly status: "completed" | "failed";
  readonly initialAgentName: string;
  readonly finalAgentName: string;
  readonly startedAt: string;
  readonly completedAt: string;
  readonly durationMs: number;
  readonly providerCalls: readonly ProviderTrace[];
  readonly tools: readonly ToolTrace[];
  readonly handoffs: readonly HandoffTrace[];
  readonly guardrails: readonly GuardrailTrace[];
  readonly retries: readonly RetryTrace[];
  readonly middleware: readonly MiddlewareTrace[];
  readonly error?: TraceError;
}
```

## Using `InMemoryTraceExporter`

Collect and query execution traces across multiple runs:

```typescript
import { InMemoryTraceExporter, Runner } from "ezagent";

const exporter = new InMemoryTraceExporter();
const runner = new Runner({ traceExporter: exporter });

await runner.run(agent, { input: "Query 1" });
await runner.run(agent, { input: "Query 2" });

// Retrieve trace by run ID
const trace = exporter.get("run_id_here");

// List all captured traces
const allTraces = exporter.list();
console.log(`Captured ${allTraces.length} execution traces.`);
```
